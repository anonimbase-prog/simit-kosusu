# 🥯 Simit Koşusu

İki kişilik, Overcooked tarzı İstanbul mutfak oyunu.

Her güncellemede GitHub otomatik olarak üç şey üretir:

- **Android:** "Releases" sayfasındaki `SimitKosusu.apk`
- **iPhone (imzasız):** "Releases" sayfasındaki `SimitKosusu.ipa`. Sideloadly ya da AltStore ile kurulur.
- **Web:** GitHub Pages adresi. iPhone'da Safari'den açıp "Ana Ekrana Ekle" ile uygulama gibi kullanılır.

## Online oynamak

"Online, iki telefon" bölümünde biri **Oda kur** der, diğeri 4 haneli kodu girer. Bağlantı internet üzerinden telefondan telefona kurulur.

## Güncellemek

Yeni `index.html` dosyasını yükleyin. Gerisini GitHub kendisi derler.
